# 🚀 UniSummarizer

> Transform PDFs and notes into AI-powered summaries, flashcards, and quizzes in seconds.

![UniSummarizer Banner](assets/img/logo.png)

## 📖 Overview

UniSummarizer is an AI-powered study assistant designed to help students learn faster and revise smarter.

Upload PDF notes or paste study material, and UniSummarizer automatically generates:

* 📄 Concise summaries
* 🎯 Key points
* 🧠 Interactive flashcards
* ❓ Multiple-choice quizzes (MCQs)

The platform also provides a personal dashboard where users can save and organize their learning materials for future revision.
