# 📘 UniSummarizer

UniSummarizer is an AI-powered web application that helps students quickly understand long academic content by converting PDFs and text into clear, concise summaries. It is designed to save time, reduce information overload, and improve study productivity.

---

## 🚀 Features

- 📄 Upload PDF files or paste text content  
- 🧠 AI-generated accurate and concise summaries  
- ⚡ Faster revision and exam preparation  
- 🎯 Student-friendly and simple UI  
- 🌐 Web-based – accessible from anywhere
- Login & Register Account
- Dashboard   

---
